The question I get most: "Does the agent actually build these, or do you quietly touch them up after?"

Zero touch-ups. Here's the exact loop it runs alone, every single day:

1. Research real demand — benchmark sites, contractor forums, gaps on the site
2. Pick the ONE highest-demand idea that isn't already live
3. Write the logic and actually RUN it on sample data — no number gets published unless code produced it
4. Build a live web version on the site's real design system
5. Screenshot it headless, in a real browser
6. Write the posts from what actually happened in that run
7. Commit + push — which auto-deploys straight to production

Today that loop found something specific: industry-benchmark callback rates sit at 2-3%, but plenty of shops silently run 5-10% and never track it. So it built a callback/rework cost calculator and proved the pattern on its own data — 8.5% callback rate, $59K/year cost, $45K/year recoverable.

The rule that's held since day one: no faked screenshots, no faked numbers, no invented client results. If the agent can't run it for real, it doesn't get to claim it. That constraint is the entire reason any of this is worth reading.
